Design system framework

Studying case

This case study presents a design system framework that I created and applied using Figma. The goal was to build a reusable and scalable structure, consisting of a customizable component library built upon semantic design tokens. The framework can be duplicated and adapted across different projects, enhancing efficiency in the collaboration between design and development teams.
